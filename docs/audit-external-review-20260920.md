## 二、独立发现清单（按风险排序）

### F1 [P3] 声明数字可复算，但**推导链未随声明给出**（三种读法三种分母）

- 现象：`README.md` / `RELEASE-CHECKLIST.md` / 发行说明声明「v3.1.0 部署后实跑 24 针 22 PASS（91.7%）」，但未就地给出该分母的构成；读者需自行推断范围。
- 复核结论（E1，**声明成立**）：按其推导档 `docs/roadtest-loop-plan-3.1.md` 的范围口径可精确复现——24 针 = `v310-precheck` 1 行 + `v310-inf-01` 20 行 + `v310-inf-01r` 2 行 + `v310-inf-02` 1 行；PASS = 1+19+1+1 = 22，FAIL = 2（= 91.7%）。作废行（`env_death`）全数剔除，`inf-03/03r/04` 有效 0 行故不进入分母。
- 摩擦点：同一批数字存在三种自然读法且各得不同分母——①按「`v310-inf-*` 全系列」重算 = **25 有效 / 23 PASS**（多算了声明后新增的 `inf-05` 2 行、漏掉非 `inf-` 前缀的 precheck 1 行）；②按「剔除双击复采」读法 = **23 有效 / 22 PASS**；③按声明口径 = **24 / 22**。分子 22 在三种读法中有两种成立，分母各有偏差。
- 影响：不构成数字错误或虚假声明，但构成**可复算性摩擦**——`细则 #368`（结论须可复算、须带指纹）要求读者能重算，而重算入口依赖另一份文档的范围说明。
- 处置：本轮为 `scorecard_agg.py` 新增可选开关 `--exclude-recollect`（使「剔除复采」读法可机检，默认行为不变）+ README 该行补口径脚注（范围 / 作废剔除 / 复采计入）；明细见 §六。

### F2 [P2] 自定容量上限未执行：`memory/agent-log.md` 流水区 221 行（阈值 200）

- 现象：`SKILL.md:199` 与注入核心均规定「流水区 >200 行或教训区 >150 行 → 移 `agent-log-archive-YYYY-MM.md`」；实测当前档流水区 221 行、教训区 29 行。
- 证据（E1/E2）：分段行数实测（状态段 9 行 / 教训区 29 行 / 偏好段 15 行 / 流水区 221 行，文件合计 281 行、261.5 KB）。

- 影响：跨会话开工必读面体积失控，直接命中该文「memory 熵增」的指控——且证据来自本仓自身。
