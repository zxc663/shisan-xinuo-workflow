# jz-06 · 会员订阅（Subscription Billing）

## 一句话

做一个会员订阅管理页：选方案开通、升级降级、取消订阅、看历史账单。

## 背景与约束

- 用户提供 14 天免费试用，试用到期未订阅则降级为只读。
- 核心动作是**选方案并开通**（试用转付费是本页北极星动作）。
- 支付失败是常态路径：必须有明确的重试与人工支持出路，不能让用户卡死。
- 取消订阅后账号保留至期末，不立刻断供。

## 明确不做

- 不做团队席位/多账号（本期单人订阅）。
- 不做优惠码/促销系统。
- 不做发票抬头管理。

## 术语

- plan = 订阅方案（basic/pro）；trialing = 试用中；past_due = 逾期未付；proration = 按比例补差价。
