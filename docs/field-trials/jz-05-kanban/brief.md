# jz-05 · 团队任务看板（TeamBoard）

## 一句话

做一个团队任务看板页面：三列（待办/进行中/已完成），卡片可拖拽跨列改状态，可新建/删除任务。

## 背景与约束

- 用户：5-15 人小团队，每日站会围绕看板过任务。
- 核心动作是**拖拽改状态**——拖拽是任务状态变更的一等交互，不是点缀。
- 任务被阻断时要能标记 blocked，阻断态必须有明确出路（解除阻断回到看板）。
- 归档任务不可再拖拽，只读留痕。

## 明确不做

- 不做多人实时协同冲突提示（本期单人视图）。
- 不做甘特图/时间线视图。
- 不做移动端专门适配。

## 术语

- 列（column）= 待办/进行中/已完成；卡片（card）= 单个任务；blocked = 阻断态。
