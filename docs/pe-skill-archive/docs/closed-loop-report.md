**判读（两条，均为判据集问题而非工具质量问题）**：
1. **转换级完备性缺判据**：C2/C4 只查「态级存在性」（错误态至少有 1 条出路），不查「契约 §③ 声明的**每条**出路都在」→ 单条恢复转换缺失结构性不可见。协议 §三 的「缺失可检出」在**行级**才成立，而现有判据停在**态级**。
2. **引用完整性缺判据（报告未覆盖，本次新增）**：C1-C5 无一校验「每条转换的 target ∈ states」——删除/改名一个状态而漏改入边（`exporting--EXPORT_FAIL-->` 指向不存在的态）**exit=0**。这是结构性无效，不是"粒度语义"，属门禁该查而没查。

## 3 报告自身的独立复核（18 条 → 复评为有效）
