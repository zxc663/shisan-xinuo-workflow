## 二、新增条款（细则 405 条 / 32 类，编号至 `#406`）

- **#375-#390（0928 裁决批 16 条）**：Mimosa 门三形态、commit-less 先例、三线 loop 环境死亡处置等，全部带当日实录出处。

2. 语义扩写层：60 族同义扩写 + E6 修复（2-gram 假阳性治理）；
3. **嵌入兜底层（本版新增）**：本机回环 socket + bge-m3 406 条索引（1024 维），余弦绝对阈值 0.55 定标（垃圾 ≤0.475 不召回 / 真查询 ≥0.55 召回）——关键词层不中时的最后兜底。冒烟实证：白屏口语化查询命中 `#397@0.591`，垃圾查询返回 0。
