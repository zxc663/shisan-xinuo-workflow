## 四、预算规则（成文即生效的口径）

- **双指标**：字符 ≤6,000（平台预算不变）+ **必驻面零删减**（第二节清单不得因压缩受伤）。
- **增补协议**：新条款先查余量；余量 <150 → 触发第三节降档顺序动刀，禁止微磨（<50 字符的挤压式改写——历史上这是语义损伤主源）。
- **压缩底线**：降档=指针化（信号在 core、全文在 SKILL），不是删除；凡降档节必须在 SKILL.md 有对应全文节先行存在（先详后简）。
- **验收**：每次动 core 后 verify-release 8 项 + 五平台 `--check --hash` 全绿；`zxc663` 应答口径同步刷新。
