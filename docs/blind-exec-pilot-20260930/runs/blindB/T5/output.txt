## 结果

**根因**：`sync()` 原实现（`sync.py:27-34`）用一个 `try` 包住 读→转换→写 三个阶段，`except Exception: return False` 把异常（连同出错环节）整个吞掉——这是"完全查不出哪个环节出错"的直接原因。

**改法**（`sync.py`，仅动两处、共 +9 行）：
- 顶部加 `import sys`；
- `sync()` 内加阶段标记变量，失败时向 stderr 打印 `sync failed in <read|transform|write> stage: <异常类型>: <异常消息>`，随后照旧 `return False`：

```python
def sync(src, dst):
    """读 → 转换 → 写；失败时在 stderr 标明出错环节，返回值仍为 True/False。"""
    stage = "read"
    try:
        data = read(src)
        stage = "transform"
        cfg = transform(data)
        stage = "write"
        write(dst, cfg)
        return True
    except Exception as exc:
        print(f"sync failed in {stage} stage: {type(exc).__name__}: {exc}", file=sys.stderr)
        return False
```

两个细节取舍：异常消息用 `str(exc)` 而非 `repr(exc)`——`OSError` 的 `repr` 会丢掉文件名，`str` 保留路径（"偶尔失败"时能直接定位是哪个文件）；异常捕获面与原先同为 `Exception`（`KeyboardInterrupt`/`SystemExit` 行为不变）。
