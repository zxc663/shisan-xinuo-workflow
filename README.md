# Shisan Xinuo Agent Workflow · 十三希诺 Agent 工作流

> 一套「让规则被消费」的执行手册型工程治理元 Skill。设计意图不是「写更多规则」，而是 **给规则装触达端口**（错误必经句 / 预读 TOP / 命中取证 / 三路合并），并用可复跑工件（GATE 块 / syncer.py）让「做过 ≠ 说过」。

## ① 定位与意图（重构的基准）

| 层 | 意图 | 落地机制 |
|---|---|---|
| 对用户 | **防假实现、可审计**——「无验证证据不称完成」 | GATE 完成块（可复跑 cmd+exit）/ 五查 / 复述增强 RE |
| 对模型 | **省 token、注意力经济**——大模块才走全流程 | L2-S 短工作流 / 调研矩阵 / 上下文卫生 / 状态面预算行 |
| 对 Skill 自身 | **可进化**——规则被消费而非登记 | 错误必经句 / mustread 预读 / 命中取证（0 照报 0）/ 双击晋升 / 自更新三路合并 |

**核心设计判断（诚实口径）**：细则层（details 238 条/13 类）此前工程消费命中 = **0**（v1.13 审计实证）——「写规则」不产生消费，**消费靠触达端口**：① 报错时**必经** details 症状类 ② 开工**必读** TOP 预读 ③ 会话末**取证**命中数（0 照报 0）。

## ③ 执行路径（何时用 · 怎么用）

| 路径 | 触发 | 怎么走 |
|---|---|---|
| L1 快速通道 | 小/可逆/低影响 | 一句话复述 → 最小改动 → 最小验证 → 汇报 |
| **L2-S 短工作流（默认）** | ≤3 文件单域；§5 三问 <2 命中 | ①**对接真相清单表**（模块\|API\|对接方式\|证据来源——禁止凭命名直觉）②改哪/影响什么/怎么验 ③单文件直做 ④最小验证 ⑤GATE 行 |
| **L2-F 完整 11 步（大模块专属）** | 三问 ≥2 命中（≥3 包跨层/契约·架构·迁移·发布·安全/用户点名严格）或 L3 | 11 步每步有出口产物（含步骤 8 产品视角五问强制、步骤 9 计划+验收 3-5 条+回滚点） |
| 必问协议 | 方向/边界/冲突/权限/密钥/破坏性/范围扩张模糊 | 先问后写；**每个问题必带推荐选项+核心理由+失败后果**；提问工具超时空答→能取消则取消，否则按项目实况给出最贴合方案并标注「待用户确认」，**空答绝不当批准** |

**复述增强（RE，最新增）**：关键决定/换方向/确认口径 → **立即**一句话子复述 `决定 X｜依据：证据/用户口径/原因｜影响：范围` 记入任务记录；任务块收尾做总复述（决策链/依据链/影响面/未决点），**子复述仅提炼要点进总复述**——用户全程知道「模型根据什么做了什么」。

## ④ 治理件（每块一用）

- **GATE 完成块**：`GATE: {v,cmd,exit,files,lessons,exempt}`——可复跑工件优先于自述；验收权在用户；approval:never 只豁免工具级审批，不豁免确认义务。
- **交付五查**：遗漏需求 / 边界情况 / 临时代码 / 无关改动 / **错误是否已接日志模块**（diff 回扫 `console.`/空 catch 零容忍——有日志模块的项目必做）。
- **会话状态面**（结束输出，给用户复核的一致性报告，非达标声明）：注入版本 / 细则命中取证行（grep，0 照报 0）/ 上下文预算与压缩阈值提醒（150-200K）/ 版本一致性（副本 vs 源库）/ 未验证与待办。
- **记录纪律**：时间戳**秒级** `YYYY-MM-DD HH:mm:ss`；活头部校验（更新正文必同步头部）；任务记录 >120 行或跨 >3 块 → 开新文件；决策改判（A4）与验收变更（A5 范围变更）同栏留档。

## ⑥ 自更新与合并（v1.17 起）——你的本地规则永不丢

- **更新方式**：上游更新后跑 `python scripts/syncer.py`（一条命令）：体检 diff（列出副本中「上游没有的文件」=你的内容）→ 备份 `.bak-<时间戳>` → 非源库件**迁移进 `user-notes/`** → 上游覆盖（SKILL/references/templates）→ 输出变更清单 + **双落盘**（仓库与副本两侧 `memory/task-log/`）。
- **合并分层表**：源库权威（判级/红线/必问——三级一致）→ 上游胜；**`user-notes/` 与 `memory/` 与 `.bak-*` → 永不碰（本地用户规则优先）**；可并存文件 → 两边都留；无法裁决 → 保留本地 + `CONFLICT` 标注等你。
- **手动改副本只许写 `user-notes/`**（否则下次同步被覆盖——这是曾经的真实教训：我们此前用 `cp` 整体覆盖同步）。
- **FAQ-嵌入**：被覆盖的本地文件如何恢复？——副本旁 `.bak-<ts>` 还原，或受迁移的 `user-notes/` 中找回；同步后先读 `sync-log-*.md` 变更清单。

## ⑦ 真实数据与诚恳（2026-08-30 实证）

- **成本**：本 Agent 平台 `model_usage` 累计 **input tokens 947,218,098（9.47 亿）** / output 2,188,313 / reasoning 249,823 —— 你「6 亿/十亿」口径成立（本平台单侧近 9.5 亿，跨平台总计合理超十亿）。
- **好的**：19 会话 *context_exceeded=0 / retry=0*；工具调用为主（2865/3002）必问 19 次、13+ 次全量 ci、13 个规范提交；细则命中 **0 → 有**（#228×3/#229×2/#233×1，触达端口后首次真实消费）。
- **坏的（同样摆出）**：3 长会话占全平台 input **81%（7.66 亿）**；单会话峰值 **3.32 亿 input（803 请求）**、单次输入 652K、无压缩；6 次计划拒绝 + 6 次「继续」的重复重召是主要成本推手；细则层此前长期 0 命中。
- **未验证假设**：规则能否改变 AI 行为——T-027 式对照实验列下一轮；**verify 绿 = 体系与自身一致，非行为变好**（EVIDENCE §五 拒绝伪精确，沿用）。
