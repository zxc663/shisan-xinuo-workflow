## 〇 域 · 元品味（作者裁决，最高权重）

0.【风格】**产出任何东西（代码/组件/文档/工件/约定）前 → 先问「它未来要谁维护、多久一次、改一处牵动几处」**｜精致偷懒的严格判据=**最小化未来维护面，而非最少行数**（50 行抽象基类可能比三处 10 行重复欠更多债——抽象本身是负债）；新增一个「需要被记住的东西」（约定/配置/特例/文档）=欠一笔债，能不欠就不欠｜用户裁决 2026-09-21（「少制造未来需要维护的东西」）；同源：ponytail「最好的代码是没写的代码」、Tufte data-ink ratio｜原文读过（用户原话）

## A 域 · 结构层（statechart/流程）

1.【共识】**功能面≥3 状态或含异步流转 → 先写 statechart 再写组件**｜无状态机定义=结构层缺失｜补定义并跑 statechart-gate｜Harel 1987/XState｜原文读过
2.【共识】**列表插入/删除/状态翻转无标记 → 变化盲视必然漏感知**｜flash 高亮渐隐 1-2s 或过渡动画｜变化盲视研究；本土：仪表盘更新感知｜转述可靠

## B 域 · 不难用底线（一票否决）

3.【共识】**错误信息无出路（只报错不指路）→ 反人类**｜正例「API Key 无效——到 设置→接入配置 生成新 Key」反例「Invalid key」｜vercel 准则；Nielsen #9｜原文读过
4.【共识】**屏幕无下一步（dead end）→ 缺陷**｜空态/终态必须有跳转或恢复动作｜vercel「No dead ends」；本土：仪表盘空态无引导缺陷｜原文读过
5.【共识】**按钮点了没反应（inert interaction）→ 假功能**｜未经真渲染取证不得声称已连接｜anti-ui-slop；本土：classifyNotice 死代码教训｜原文读过

## C 域 · 不难看底线

6.【风格→共识化】**AI 味三件套（紫渐变/无意义发光/圆角滥用）→ 零容忍**｜配色走主题令牌、装饰服务于层级｜taste-skill 二值化禁令｜转述可靠
7.【共识】**层级靠加大字号 → 高密度失控**｜层级=字重+灰度+间距（4/8 网格），字号档 ≤3｜Material type scale；G 档｜转述可靠

## D 域 · 时序纪律

8.【风格】**先选组件再定交互（组件驱动设计）→ 一票否决**｜交互承诺先行，组件是兑现手段；「对」比「原创」重要（复用+二开）｜Cooper 目标导向；本土 AGENTS 第 5/13 条（2026-08-13 固化）｜原文读过

## E 域 · 无障碍底线

9.【共识】**状态用纯颜色表达 → 色盲+变化盲视双杀**｜颜色+图标/文字/位置冗余线索｜WCAG 1.4.1；vercel｜转述可靠
10.【共识】**先加 ARIA 后想语义 → 治标**｜语义 HTML 优先（button/link/native input），ARIA 只补语义表达不了的｜vercel「语义先于 ARIA」；WCAG POUR｜转述可靠

## F 域 · 感知与过渡（G 档，全部【共识】）

11. **列表插入/删除/状态翻转无标记**→变化盲视必然漏感知｜flash 高亮渐隐 1-2s 或过渡动画｜变化盲视研究；G1｜转述可靠
12. **异步加载用居中 spinner+布局跳动**→高密度灾难｜骨架屏锁布局（CLS≈0）｜vercel/Nielsen 阈值；G2｜转述可靠
13. **浮层无 elevation 语义平贴**→层级失真｜阴影/遮罩/边框按层级表｜Material elevation；G3｜转述可靠
14. **一屏字号档位>4**→层级失控｜收敛进 type scale ≤3 档｜Material type scale；G4｜转述可靠
15. **分组用框中框**→密度失控前兆｜间距分组优先（格式塔接近性）｜Gestalt；G5｜原文读过
16. **密度拍死一档**→场景错配｜提供紧凑/标准切换｜Ant/Lightning 密度系统；G6｜转述可靠
17. **数据异步静默刷新**→用户失察或困惑｜乐观更新或更新标记+失败回滚通知｜乐观 UI 共识；G7｜转述可靠

## G 域 · 结构层补充（H 档）

18.【风格】**状态流转无 statechart 源（≥3 态功能面）**→契约不可判定｜statechart JSON 为源、表格为视图｜Harel 1987/XState；H1｜原文读过
19.【共识】**非终态无出边**→死端=出路缺失的结构态｜补恢复/逃逸转换（statechart-gate C2 拦截）｜H2/Nielsen #3｜原文读过
20.【共识】**并行子状态扁平枚举**→组合爆炸｜层级状态/并行区域建模｜Harel；H4｜转述可靠
21.【共识】**转换无守卫说明**→竞态/重复触发不可审｜守卫条件写入翻译表（statechart-gate C5）｜XState guards；H5｜转述可靠

## H 域 · 性能与节奏（F 档缺口）

22.【共识】**异步等待无节奏**→焦虑或失察｜0.1s 即时/1s 心流上限（超必给进度）/10s 注意力上限（超必可取消）｜Nielsen 响应时间阈值；interaction-bridge 六问②｜转述可靠
23.【风格】**动画无频率审**→高频操作被动画拖慢｜先过动画四问（频率→目的→easing→时长）再落 | emil；anti-excuses #5｜转述可靠
