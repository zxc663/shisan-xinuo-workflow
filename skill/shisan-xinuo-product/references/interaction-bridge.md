# interaction-bridge · 联通层细则（来源三合法/六问/翻译表/双底双顶）

## 1. 来源三合法（交互逻辑从哪来，冲突序=红线>用户心智>功能推导）
1. **用户心智（最强源）**：业界惯例+项目既有裁决。惯例=预装在用户脑里的交互逻辑，用惯例=零学习成本；反人类的高发机制=迫使用户为你的实现学一套新交互。
2. **功能语义推导**：交互逻辑不是发明的，是功能自带欠条的偿还（六问）。
3. **红线约束**：出路/六态/承诺/无障碍不可违。
**非法源**：组件库存（组件驱动设计=先选控件后定交互，一票否决）、模型感觉、「看起来酷」。

## 2. 功能天生六问（Norman 行动七阶段+两个鸿沟的工程压缩版，出处挂靠）
| # | 问 | 答案落点 | 学科出处 | 信心级 |
|---|---|---|---|---|
| ① | 输入什么 | 选择器/表单/拖放/导入——示能与意符 | Norman 执行鸿沟 | 原文读过 |
| ② | 何时发生/多久 | 进度/骨架屏/乐观更新；**0.1s 即时/1s 心流上限（超必给进度）/10s 注意力上限（超必可取消）** | Nielsen 响应时间阈值 | 转述可靠 |
| ③ | 成功长什么样、落在哪 | 成功态+落点（回哪个页/哪个高亮）| Norman 评估鸿沟 | 原文读过 |
| ④ | 怎么防失败→没防住怎么恢复→出路 | 防错（约束/校验时机）>恢复（重试/回填）>出路（指路到动作） | Nielsen #5>#9 | 转述可靠 |
| ⑤ | 能否反悔、代价多大 | 撤销窗/确认窗/幂等；破坏性=确认+undo 安全窗（~5s） | Nielsen #3；本土：ListRow+5s 撤销 | 混合 |
| ⑥ | 下次/换环境还认吗 | 持久化/一致/并发/深链/设备/语言/弱网 | 概念模型一致性 | 原文读过 |
劝导级第 7 列：**情绪目标**（该环节用户该感到安心/掌控/惊喜——Journey Map emotion lane）。

### 翻译表 schema（源=statechart JSON/TS，表格只是视图）
```json
{
  "id": "import-wizard",
  "initial": "idle",
  "states": {
    "idle":    {"on": {"SELECT_FILE": "parsing"}},
    "parsing": {"on": {"DONE": "review", "FAIL": "error"}},
    "review":  {"on": {"COMMIT": "done", "CANCEL": "idle"}},
    "error":   {"on": {"RETRY": "parsing", "ABORT": "idle"}}
  }
}
```
门禁：无死端（非终态全有出边）/全可达/错误态必有恢复转换——`scripts/statechart-gate.py`。

## 3. 双底双顶+第四底
不难用（六问全答+反面零容忍）｜不难看（AI 味清单零容忍）｜**无障碍（WCAG POUR：可感知/可操作/可理解/健壮；axe 静态子集）**｜更好用（渐进披露/频率适配，根=认知负荷+Hick）｜更好看（过渡语义/层次质感，Norman 行为/反思层）。

## 4. 联通行（验收单元）
