# capability-map · 能力地图（动作时点×任务症状 → 能力 → 出口产物）

> 衰减链第 2 级（计划不引用）的治具；工作流×本包的互补路由层。**harvest 机制**：定期扫 skills 目录+frontmatter diff 更新本表（无人维护的地图=第二个失忆）。先例：「项目/」踩坑经验库（开工必读+症状检索+四段式）。

| 动作时点 | 任务症状 | 能力（Skill+章节/命令） | 出口产物 |
|---|---|---|---|
| 开工前 | 不知道在解决哪一层的问题/上游没定就要落地 | layer-stack 层级门（步骤 0a） | 层声明 + 上游确认结论（或回补清单） |
| 开工 | 任何用户可见功能 | 本包 §2 跑道（步骤 0=层级门+产品对象六问） | 功能句+六问翻译表 |
| 设计前 | 「这页该有什么功能/什么最重要/后台能不能管」 | product-object.md 六问+两级清单 | 能力清单+主功能+闭环缺口 |
| 设计前 | 不知道该长什么样 | ux-feature-design 六态审查+本包六态矩阵 | 六态（态+转换）矩阵 |
| 设计前 | 需要灵感/风格 | ui-ux-pro-max CSV 检索；impeccable 打磨 | 风格裁决（入账本） |
| 计划时 | 功能/前端任务 | **能力地图检索位**（本表）+工作流复用五问 | 检索记录（归因） |
| 落地前 | 要用什么组件 | registry.md 查表+上游组件库（能力索引视图） | 兑现方式行（现有组件 X/新件 Y+归因） |
| 落地中 | 新组件/新依赖冲动 | registry-gate.py | 归因注释或拦截 |
| 交付前 | 「做完了」 | spec-trace 双向+取证（截图/DOM） | 联通行清单 |
| 交付前 | 状态流转存疑 | statechart-gate.py | exit 0/1 |
| 收尾 | 本次有新裁决 | decision-ledger 写回 | 账本新增行 |
| 复盘 | 同类问题再现 | 账本检索+踩坑经验库 | 既有结论引用 |
