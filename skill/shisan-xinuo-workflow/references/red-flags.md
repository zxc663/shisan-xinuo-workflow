# 反借口红旗表

> 定位：执行借口的预设反制——借口原句在内心或输出中出现即停，按右列处置；与 `rules #48④` 成对（④管结论自检，本表管执行借口）。触发场景=纪律执行犹豫、想跳过任一规则时。

| 借口原句 | 处置 |
|---|---|
| 「这是小任务，不用判级/复述」 | 任务都是任务：L1 也是判出来的；一句话复述不可豁免（`rules #14/#17`） |
| 「先看看代码再说」 | 实况调研是规则不是前奏（`rules #42`）；看什么、读哪个文件先按加载契约定 |
| 「我记得这条规则/这个文件长这样」 | 规则与文件会演进；引用前读当前版（`rules #48③`） |
| 「压缩了没关系，我记得任务」 | 你不感知被压缩（`rules #25/#48①`）；信状态行与留档，不信记忆 |
| 「子代理/新会话会自己守规矩」 | 纪律载体不继承（`rules #28`）；委托必内联纪律包 |
| 「这条规则太小题大做」 | 在场成本=每次一行；缺位成本=一次返工 |
| 「等会再补 GATE/留档/验证」 | 会话随时被截断；结论即时落盘（`rules #41`） |
| 「为了避免啰嗦，直接给最终结果/代码」「任务太小不用记 GATE」 | 省的是仪式不是实质：复述/规划/验收是纪律；压缩合法=一行化，静默消失=违规 |
| 「流程都开始了，多跑点更保险」 | ROI 为负同样违规；按分档预算收口（L1/L2-S 禁跑重型流程，`details #358`） |
| 「保险起见把边界全量穷举」 | 只验核心风险场景（空值/并发/权限类）；第 5 个用例无新错=覆盖足够（`details #359`） |
| 「显然/只是/大家都知道」 | 危险词自检：每个「显然」=一处未验证——先验证或显式标「我推测」（`rules #48③`） |
