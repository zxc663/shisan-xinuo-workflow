# lessons.md · 教训账（踩坑教训独立账本）

> **定位**：踩坑教训的独立账本——教训不再挤占条款账零和。条款=工作流行为规则（仍在 `details.md`，405 零和上限）；教训=实战踩坑记录（本账，**解冻不占 405**，靠生命周期代谢，不设硬上限、半年审账）。
> **入口工作流**：`shisan-xinuo-flows` §11 教训生命周期与上下文卫生。

## 入库格式（缺一不合格）

`N. [域:通用|平台=<名>|环境] [态:active|fixed|retired] [分类] 症状一句话｜根因｜解决｜预防｜证据=<用户原话引号+日期 或 错误栈原文>｜命中: n`

- **域**（判据=教训的因果是否依赖特有机制，**专名≠环境**）：`通用`=Agent/工程共性层，任一平台可复现｜`平台=<名>`=绑定特定平台行为（如 DSH 信封包裹、Mimosa 插件拦截）｜`环境`=绑定本机软硬件/私有配置，跨机器不可复现。
- **态**：`active`=在库生效｜`fixed`=上游已修复（**修复判定三要件**：真实调用链复现 ≥2 次不能复现 + 对照组阳性〔已知坑仍复现〕+ 平台版本锚定；缺一=未定论不动）｜`retired`=已退役（编号入退役清单，**不复用**）。
- **反论证三问**（入库前置，写在条目尾）：删掉这条最坏后果（有判例引判例，无判例标「预防性」）｜会被怎么误读（反向样例）｜有无更短等价表述。
- **证据**：用户原话（引号+日期锚）或错误栈原文——**禁 agent 代拟用户言论**，无原话不归因只记决策内容（红线「记录诚实性」）。

## 生命周期

- **处置三出口**（fixed 后裁决）：① `retired`（通用性无残留，删除移清单）② 留库标版本上限（`fixed` 态本身=老版本用户仍有效的警告）③ 合并上位（沉淀出通用原则→并入条款账，本条 retired+回指）。
- **复活**：retired/fixed 症状再现（平台回退/新平台同症状）→ **新编号立条+回指退役编号**，复发链记档，命中重开。
- **审账节拍**：不设硬上限；半年一审（健康度=retired/fixed 占比、复活率、误判率）。

## 迁移计划（双库批施工）

存量踩坑教训自 `details.md` 分拣迁入（普查批逐条三裁决：域+态+反论证）；分拣判据=「行为规则（告诉 agent 怎么做）留条款账 / 踩坑记录（某次怎么踩的+怎么爬出来）迁本账」。账本先立，迁移施工前本账 0 条为合法初态。
